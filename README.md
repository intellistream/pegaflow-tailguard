# PegaFlow TailGuard

PegaFlow plugin for P/D CPU-memory placement, remote-read admission, and RDMA
tail-latency control.

This repository is reserved for the plugin proposed in
[vLLM-HUST/pegaflow-hust#23](https://github.com/vLLM-HUST/pegaflow-hust/issues/23).
Implementation and experimental artifacts will be added later.
