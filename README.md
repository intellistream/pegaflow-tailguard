# TailGuard standalone prototype (superseded)

This repository preserves the historical standalone TailGuard proposal. It is
no longer an independent active research topic.

The current **TailGuard** topic—P/D host-memory placement, remote-read
admission, and RDMA tail-latency control—is carried by
[`vLLM-HUST/pegaflow-hust`](https://github.com/vLLM-HUST/pegaflow-hust), where
PegaFlow remains the software and repository name. See the active
[TailGuard issue](https://github.com/vLLM-HUST/pegaflow-hust/issues/23).

No implementation, experiment, score, or claim should be transferred from the
PegaFlow carrier into this stopped prototype record. This repository remains
available only for provenance.
